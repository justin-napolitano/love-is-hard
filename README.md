# love-is-hard

A reflective personal project exploring themes of love, connection, and existential struggle through written narrative. This repository contains a single markdown document presenting a candid, introspective essay.

## Features

- Introspective essay on love and human experience
- Structured in markdown for easy reading and potential reuse

## Tech Stack

- Markdown (.md) format for content
- No programming language or framework involved

## Getting Started

This repository contains a markdown file and does not require installation or runtime environment.

To view the content locally:

```bash
# Clone the repository
git clone https://github.com/justin-napolitano/love-is-hard.git

# Navigate into the repo
cd love-is-hard

# Open index.md with any markdown viewer or text editor
```

## Project Structure

```
love-is-hard/
└── index.md      # Primary content file containing the essay
```
